# Problem Statement

Many basic computer vision tasks begin with understanding pixels, color channels, filtering, edges, and contours. This project demonstrates these concepts with simple OpenCV operations.

## Scope

The program processes one local image at a time from the command line. It supports preprocessing, enhancement, edge detection, simple shape detection, and statistics.

## Target Users

Computer Vision students and evaluators who want a small, readable example of fundamental image processing.

## High-Level Features

Image transformation, blur and threshold operations, Canny edges, contour-based triangle/rectangle/square/circle labels, and image statistics.
